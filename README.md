🔐 Password Generator

A simple and responsive Password Generator built using HTML, CSS, and JavaScript. This project helps users generate random and secure passwords with ease.

✨ Features

- Generate random passwords.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.
- Copy generated passwords to the clipboard.
- Customize password length and character types (if implemented).

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
